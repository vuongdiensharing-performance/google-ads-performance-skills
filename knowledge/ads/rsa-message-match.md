# RSA and Message Match

## Principle

Search ad messaging should be relevant to the user's intent and consistent with the landing-page promise.

## RSA guidance

- Provide multiple distinct, useful assets rather than many minor rewrites.
- Include relevant keyword language where it improves relevance without making copy unnatural.
- Avoid unnecessary pinning because excessive pinning limits combinations.
- Use Ad Strength as directional feedback, not as a substitute for business performance.
- Evaluate ads using conversions and conversion quality, not CTR alone.

## Message-match chain

Search term → keyword/theme → ad promise → landing-page content → conversion action.

A break in this chain is a diagnostic signal.
