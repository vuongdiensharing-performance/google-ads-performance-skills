# Agent Operating Contract

## Scope

This repository contains Google Ads performance marketing skills, knowledge, and evidence-based rules for model-agnostic AI agents.

## Required behavior

- Inspect available evidence before making performance claims.
- Never fabricate account, campaign, keyword, conversion, spend, or revenue data.
- Distinguish observation, inference, recommendation, and confidence.
- State data gaps when evidence is insufficient.
- Prefer business outcomes and conversion quality over vanity metrics.
- Treat thresholds as contextual unless explicitly documented as fixed platform constraints.
- Use the smallest relevant set of skills and rules for a task.
- Account-changing actions are recommendations/preparations by default; execution requires human approval.

## Asset hierarchy

1. Official Google/platform documentation when applicable.
2. Verified first-party/platform data.
3. Validated repository methodology.
4. Industry best practice.
5. Source-repository patterns.
6. Model inference.

Higher-authority evidence wins when sources conflict.

## Output discipline

Every diagnostic workflow should expose:

- Evidence
- Finding
- Impact
- Priority
- Recommendation
- Confidence
- Data gaps
- Measurement plan
